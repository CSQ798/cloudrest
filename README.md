# 云卷云舒

> 宠辱不惊，看庭前花开花落；去留无意，望天上云卷云舒。

把你的场景描述交给它，它自己挑体裁（近体诗或词牌）、按谱填字，逐字校平仄、校韵部，
再把你这一稿的**取景、立意、选韵、用典、修辞、诗病**摊在左边给你看。

```
场景输入 → 择体 → 按谱成篇（最多五稿） → 逐字校律 → 自评润色 → 排版（诗两句一行 / 词按句读连排）
```

## 两个版本

| 目录 | 是什么 | 怎么跑 |
|---|---|---|
| `cloudrest/` | **部署版**：Cloudflare Workers / Pages，账号与额度用 D1（SQLite） | 见 `cloudrest/DEPLOY-CLOUDFLARE.md`；本地 `npm run serve` |
| `node-version/` | 本地 Node 版（零依赖，`node server.js`）+ `.research/` 数据抽取与自证脚本 | `node server.js` |

两版共用同一套 `server/` 与 `public/`（字节一致）。`pack-cloudrest.ps1` 负责把部署版打成可直接拖进 Cloudflare 的 zip。

## 它凭什么说「合律」

- **词谱**：26 个词牌的句数、每句字数、逐字平仄、韵位，来自搜韵《钦定词谱》，抽取时逐条硬校验
  （总字数、每句字数、韵位顺序、例词字数四项对不上就不收）。
- **韵书**：平水韵 106 韵目（平 30／上 29／去 30／**入 17**）、词林正韵 19 部，去重 20742 字头。
  律绝按平水韵判，词按词林正韵判 —— 两本书不能混（词林正韵把平水韵的「十灰」拆进了三部与五部）。
- **句读标点**：每个词牌一张标点表，从搜韵「历代作品」里统计取通行体，
  11 个词牌按该词牌最著名例词的通行标点人工定稿（差异可复核：`node .research/extract-marks.mjs`）。
- **入声字**：白、石、竹、菊、节、月、雪… 一律判仄——这是律诗最容易露怯的地方。

## 它还会自己挑毛病

`server/disease.mjs` 是「诗病自检」，与格律校验分开：套语、颜色数字凑字、生造词、物候打架、
合掌、上尾、摞眼、重字重韵、情景两张皮、用典未落地、自报与实际不符……
**分两档**：能确证的报「宜改」（退回重写），词表/代理判定的只报「提示」（只展示，不退货）。

`server/voice.mjs` 管声情：十九部韵各自的调子、与立意相不相称。

另有一批判据照王国维《人间词话》落成，逐则清单与十二轮自评矫正的经过在
`node-version/.research/renjian-cihua-plan.md`：代字、有我无我之境、造境写境、隔与不隔、
真景物真感情、一切景语皆情语、一字境界全出、境界有大小、忌游词、无矫揉妆束。

## 测试

```bash
cd cloudrest
npm run test:all          # 离线十项：打包安全 / 页面结构 / 词牌句读 / 诗病 / 纸笺 / 账号…
node .test/worker-test.mjs   # 联网：真调模型成诗一首，验端到端
```

两条最要紧的验收线：

1. **七首名作（登高·春望·山居秋暝·锦瑟·黄鹤楼·春晓·静夜思）一处「宜改」都没有**
   —— 判据不是靠冤枉名作换来的。
2. `node .test/self-loop.mjs repeat 3` 同题重复，用来量「同一道题自身的方差」。

## 诚实的局限

- 只收 26 个已核验词牌；不收古体、排律、散曲。
- 平仄校验依韵书，多音字返「多」不苛责；孤平／拗救**没有**判（会与词谱的「中」冲突）。
- 字体、物象、典故出处只做**代理**判定；代理不退货。
- **「诗变好了」这件事没有证明**：同题自身方差就有 1~6 处平仄，要检出小效应每组约需 38 首。
  十二轮的对照实验记录在 `renjian-cihua-plan.md` 的结项一节。
- 没有与历代语料做查重。

## 数据来源与许可

词谱、韵书、典故数据抽取自**搜韵**（https://www.sou-yun.cn ）的《钦定词谱》《词林正韵》《平水韵》公开页面；
抽取脚本与校验结论在 `node-version/.research/`，**第三方页面缓存不入库**（见 `.gitignore`）。
诗词文本本身由你配置的模型生成，著作权与合规使用请自行判断。

## 密钥

`.dev.vars`、`.env` 一律不入库（已在 `.gitignore`）。
部署需要在 Cloudflare Pages 里配 `DEEPSEEK_API_KEY`（必需）、`SESSION_SECRET`（账号功能需要）、
D1 绑定变量名必须是 `DB`。
