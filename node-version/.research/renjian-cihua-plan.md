# 结项：这十二轮做成了什么，没做成什么

## 做成了（可查、可复发）

| | |
|---|---|
| 《人间词话》十则落成检查或准则 | **10/10** |
| 每则都有可复发的回归断言 | `craft-test` 的「总验收」十条，逐条跑得出来 |
| 七首名作（登高·春望·山居秋暝·锦瑟·黄鹤楼·春晓·静夜思） | **一处「宜改」都没有**（判据不是靠冤枉名作换来的） |
| 三笔欠账（首句入韵重韵、平仄假设、诗侧韵部核对） | **已还** |
| `diagnose` 的任何出口字段一致 | **已修 + 断言** |
| 对照实验的两个开关 | `CIHUA_OFF`（关掉七段准则）、`CIHUA_WARN`（关掉提级） |

## 没做成（如实交代）

**我无法证明这十则让诗变好了。** 三条证据：

1. **同题方差就有 1~6 处平仄**（同一场景同一体裁连跑三遍：2/6/3 与 2/1/2 与 2/3/3 都出现过）。
   要检出 Δ≈1.3 的差别，每组约需 **38 首**。每轮三首的数字**不能比较**——这一点从第七轮起
   写成了纪律，第十轮起有了实测数字撑腰。
2. **A/B 对照（有七段 vs 无七段）**：平仄均 2.67（有）对 1.33（无）——差值落在噪声里，**不判**。
3. **提级对照（三条客观检查进回路 vs 不进）**：两组定稿的残留都是 **0/0/0**，稿数 1/5/5 对 2/5/5，
   平仄 1/3/3 对 3/1/7 —— **提级没有换来任何可测的差别**，因为在这道题上那三条检查**本来就没触发**。

结论：这十则的价值在**诊断与展示**（把诗病摊给站长看），不在自动改诗。
要验「诗变好」，得换一个比平仄灵敏的指标——那需要人的判断，机器给不了。

## 十二轮的方法论遗产（比十则本身更值钱）

1. **判据分两档**：能确证的报「宜改」（进回路），词表/代理判定的报「提示」（只展示）。
   代理不该有权退稿——这是「七首名作零宜改」能成立的唯一原因。
2. **已知局限要写进测试**：白石「二十四桥」王国维判隔而我判不出 → 断言它必须沉默，
   并把「只报隔、不报不隔」写成规则。
3. **把判断写进测试，它会替你记住**：第十一轮我想把「代字」提成必改，
   上一轮写的断言（「代字只报提示（王国维也只是『惜』）」）当场把我拦下。
4. **同题重复才叫实验**：不同题的三首一组，只能看热闹。
# 按《人间词话》逐则优化 · 总纲与进度

站长要求「仔细按照王国维《人间词话》一步步优化，每优化一次自己赏析批评并做矫正」。
这份文件是进度表：每一则对应一次改动，改动必须**能被测试**，改完要**自出题实测**，
再自己挑毛病矫正。做不到机械判定的，就落成准则（prompt），并注明「判不出」。

## 为什么《人间词话》这套东西特别适合拿来改一个作诗器

因为它不是玄谈，它**给出的是判据**：
「能写真景物真感情者，谓之有境界」「语语都在目前，便是不隔」「词忌用替代字」
「有有我之境，有无我之境」「境界有大小，不以是而分优劣」——
每一条都在说「什么样的句子算好」，而「算不算」是能写成检查的。
这与前几轮那 115 条病不同：那些多是「水平不够」，这些是**标准**。

## 对照实验：同一道题的方差（第九轮做）

`node .test/self-loop.mjs repeat 3` —— **同一场景、同一体裁（七言绝句）连跑三遍**：

```
第 1 遍  平仄出入 2
第 2 遍  平仄出入 6
第 3 遍  平仄出入 3
```

结论（这一条比前面几轮的数字都重要）：**同一道题自身的平仄出入就能在 2~6 之间跳。**
所以前面「每轮三首」的那些数字（1／3／0、5／4／2、1／0／1）**根本不足以比较**——
每轮三首、逐首难度不同，而同一首的波动就有 4 处。想验「反馈长度」「某则准则」这类小效应，
**必须同题重复多次**，这是本轮的教训，也是往后所有实测的纪律。

## 第十一轮：把「宜改」真正接进改写回路

前九轮的实情是：十则里绝大多数是「提示」级，**只摊在页面上，诗一点没变**。这一轮把其中
**判据最硬、改起来最便宜**的三条提到「宜改」（会退回重写）：

- 游词（六十一则）· 妆束（五十六则）· 没指出那一个字（七则）

**代字没有提** —— 王国维自己也只是「惜以桂华代月耳」，是遗憾不是错；为一个代字逼它重写全篇，
反而可能丢掉好句。这条留在「提示」。开关：`CIHUA_WARN=0` 可整体关掉（供对照）。

同题三遍实测：

```
平仄出入  3 / 1 / 7       提级后不再有 [宜改] 残留（三条检查在定稿里全部沉默）
```

两点结论，一是一非：
1. **机制生效**：提级之后，三条客观检查**真的进了回路**，定稿里一处残留都没有 —— 这是可复发验证的（`[宜改]` 计数为零）。
2. **对格律的影响仍然测不出**：1~7 的散布落在先前量到的同题方差（1~6）里。**不许说它没害，也不许说它有害。**

自省：提级时我第一版把**代字**也提了，`craft-test` 里一条旧断言（「代字只报提示，不当成错
（王国维也只是「惜」）」）当场把我拦下。**那条断言写的是我上一轮的判断，它比我这一轮的冲动更对。**
这正是把判断写进测试的用处 —— 它替我记住了我当时想清楚的事。
## 对照实验（第十轮做）：加了《人间词话》七段，诗有没有变好？

开关：`systemHead()` 读环境变量 `CIHUA_OFF`；置 1 时把【…（王国维《人间词话》）】那七段整段去掉，
**其余准则原样保留**（已验证：7 段 → 0 段，长度 5405 → 3620，「不可抄袭」「要精确」等仍在）。
另有「想要有一层想头／场景有多大／先选韵再落笔」三段不属于这一批，两组都有，不参与对照。

同一道题（同场景、同体裁：七言绝句）各跑三遍：

```
A 组（有那七段）  平仄出入  2 / 3 / 3   均 2.67
B 组（无那七段）  平仄出入  3 / 0 / 1   均 1.33
```

**结论：这个实验做不出结论。** 差值 1.33，而前面量过的**同题自身方差是 1~6**（同题三遍出现过 2/6/3 与 2/1/2）。
粗算一下要多大样本才够：σ≈2、要检出 Δ≈1.3，每组约需 **38 首**（共 76 首）。
三对三的对照，**不足以判别这个量级的差别**——所以两组谁好谁坏，**我不下判断**。

能说的只有两句：
1. 六首全部**押韵合、无硬错**（句数字数都对）；
2. 这七段准则**没有在任何可测的指标上造成退步**（至少没测出来）。

这与前九轮的实情也吻合：这十则里绝大多数是「提示」级，**它们活在「诊断与展示」里**——
把诗病摊给站长看，而不是去改诗。要验它们对**诗本身**的影响，得换一个比「平仄出入」灵敏的指标
（那需要人的判断），或者把样本加到几十首。**这件事我没做完，不含糊过去。**

## 已完成的（含自评与矫正）

### 第一轮　词忌用替代字（第三十四则）

> 「词忌用替代字。美成《解语花》之『桂华流瓦』，境界极妙，惜以『桂华』代『月』耳。」
> 「白石写景之作……虽格韵高绝，然如雾里看花，终隔一层。」

落法：`server/disease.mjs` 增 `SUBSTITUTE` 表（月、雪、柳、桃、酒、琴、镜、信、笔、泪、日、山、风…）
与 `substituteFindings()`。判据只有一条：**用了代字，而那个字所代的本字其实可以直接写**。
「桂华流瓦」→ 提示「『桂华』是代字，直说『月华』」。但**放行拟人化的用法**（「蟾光」若与
蟾的字面意义无关才算代字；「玉盘」在写盘子的场合不算）。

自评：第一版只按字表硬匹配，把「六出」的「出」也报了 —— 荒谬。矫正：代字必须是**完整词**
（六出、玉龙、桂华、蟾宫）且出现在**景语**语境里，且正文里**没有本字**。若无本字而代字承担了
全部景语信息，才是「隔」；若本字已出现，代字只是复说，报「同一物两样说法」。

### 第二轮　有我之境 / 无我之境（第三则）

> 「有有我之境，有无我之境。……有我之境，以我观物，故物皆著我之色彩；
> 无我之境，以物观物，故不知何者为我，何者为物。」

落法：`server/voice.mjs` 旁的 `realm()`（新，在 `disease.mjs` 内）：按**物象与情绪的比重**
判定一首属哪一类 ——
- 有我：出现第一人称（我/吾/予/余）或**直接情绪词**（愁/恨/悲/怜/叹/怕）落在物上；
- 无我：通篇只有物、动作、光色温度，没有一个情绪字，也没有「我」。
判定用两个数：`feelingHits` 与 `selfHits`，都为零 → 无我；任一为正 → 有我。
**混合**（同一片之内既有无我的纯景句、又有直抒的情绪句）→ 报「境界不统一」。

自评（**第一版判错了，这里如实记下**）：第一版把分类的判据写成「情绪字是否**紧贴**自然物」
（寒山、愁云），于是杜甫《登高》被判成「无我之境」—— 它正是王国维拿来标举有我之境的标本，
「万里悲秋常作客」「艰难苦恨繁霜鬓」里悲、苦、恨都在，只是不着色于物。
矫正：**分类看全篇有没有情绪字与「我」字；「着色」与「直说破」是另一件事，只用来判说破。**
矫正后拿五首名作校过，5/5 全对（无我：山居秋暝、鸟鸣涧、鹿柴；有我：登高、春望），
这个坑也留成了测试里的一条反向断言。
另一处初版之误：「孤」「独」被当作情绪词，会把王维「王孙自可留」判成抒情 ——
现在只收情绪本身（愁恨悲喜怜叹怨哀怕苦欢怒愤伤惜怅），处境词不算。

## 下一轮（第四轮）要做的事

隔与不隔（第四十、四十一则）：
> 「语语都在目前，便是不隔。……如欧阳修『阑干十二独凭春』……语语都在目前，便是不隔。」
> 「白石写景之作，如『二十四桥仍在，波心荡、冷月无声』……虽格韵高绝，然如雾里看花，终隔一层。」

落法（代理，须写明是代理）：
- **不隔** = 具体物 + 具体动作 + 可感的温度/声音/光，且**没有**代字、没有堆典；
- **隔** = 代字密度 + 典故密度 + 抽象词密度 三项相加高，而实景实动少。
王国维给的正例（「池塘生春草」「空梁落燕泥」）必须判「不隔」，反例
（「谢家池上，江淹浦畔」）必须判「隔」—— 这两条进测试当验收线。
判不出的（如白石那种「格韵高绝而隔」的微妙情形）一律不报，只在左栏摊出那三个数字。

### 第四轮　隔与不隔（第四十、四十一则）

> 「**语语都在目前，便是不隔。**」「白石写景之作……虽格韵高绝，然如雾里看花，**终隔一层**。」

落法：`disease.mjs` 的 `detectGe()` 数两个量 ——
**实分**（可见之物 + 动作 + 声音/温度/光各计双倍）、**隔分**（代字×2 + 僻典词×3）。

**这一轮的落法是故意不对称的：只报「隔」，绝不报「不隔」。**
理由是王国维自己那条最难的例子：白石「二十四桥仍在，波心荡、冷月无声」，格韵高绝而被判「隔」。
我的代理在那句上算出来**实分 6**（月、波、桥、声俱全），若它敢说「不隔」，就是替王国维下了一个
错的判词。所以规矩是：**只有「典与代字的分量压过眼前实物两倍以上」这种明明白白的隔，才出声**；
其余一律沉默 —— 沉默不是「不隔」，只是「我不判」。这一句也进了测试，写明是**已知局限**。

自评（**阈值第一版就选错了**）：第一版写「隔分≥6 且 实分≤4」，结果把王国维那个反例
「谢家池上／江淹浦畔／蓝桥／洛浦」放过了 —— 它隔分 15，可实分也有 5（霜、江、草、桥），
被绝对阈值挡在门外。改判据为**分量对比**（`veil >= real * 2`）才对：
隔与不隔不在于有没有物，在于**典压不压得住景**。矫正后七条全过。

验收线（都在 `craft-test.mjs` 里）：
- 正例必须**沉默**：「池塘生春草」「空梁落燕泥」「阑干十二独凭春」；
- 反例必须**报**：「谢家池上，江淹浦畔」这一类堆僻典的；
- 已知局限必须沉默：白石那一句；
- 七首名作的总验收不许被这一条打破（仍是一处「宜改」都没有）。

> 「有造境，有写境，此理想与写实二派之所由分。然二者颇难分别。」

落法：`disease.mjs` 的 `makeOf()` —— 数两个量：**与场景相接的实字**、**虚拟与夸张词**
（若/如/似/疑/恐/欲/恍、三千/九万/万里）。只在两种证据强矛盾时说话：
自报写境而与场景几乎无实字相接、又满篇虚拟夸张（那就是「另造了一境」）；自报造境而句句落在
场景实有之物上。其余一律判「难分」，**只把数字摊在左栏给人看**。
