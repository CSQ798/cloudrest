## 出处有明确依据的条目（举证）

- **《山海经》**：精卫填海（北山经）—— 教育部《成語典》典源原文即作「《山海經．北山經》」；刑天舞戚（海外西经）、夸父逐日（海外北经）—— 陶潜〈读山海经〉三首用例与篇目互证。
- **《庄子》**：庄周梦蝶（齐物论）、鲲鹏万里（逍遥游）、涸辙之鲋（外物）、尾生抱柱（盗跖）—— 篇名与《庄子》内/杂篇篇目一致，检索到各篇全文页面。
- **《淮南子》**：嫦娥奔月、女娲补天 —— 同出〈览冥训〉（「羿请不死之药于西王母，姮娥窃以奔月」「女娲炼五色石以补苍天」）。检索到《淮南子》上古神话专题页。
- **《博物志》**：鲛人泣珠（异人）—— 教育部《重編國語辭典》引「晋·张华《博物志·卷二·异人》」；湘妃竹（卷八）—— 搜韵「按出处索引・艺文类聚」条引「《博物志》曰：洞庭之山，帝之二女啼，以涕挥竹，竹尽班」，识典古籍另有《博物志》卷八全文页；张骞乘槎（卷十）—— 搜韵该典正文即标「晋·张华《博物志》卷十」。
- **《世说新语》**：陆机华亭鹤唳（尤悔）—— 搜韵正文引「《世说新语》下卷下《尤悔》」＋《晋书·陆机列传》，并列出李白〈行路难〉「华亭鹤唳讵可闻，上蔡苍鹰何足道」；张翰莼鲈（识鉴）、山简醉（任诞）、韩寿偷香（惑溺）、桓温柳（言语）各有检索到的分篇页面。
- **《史记》**：屈原沉江、贾谊长沙（屈原贾生列传）；张良圯桥进履、商山四皓（留侯世家）；项羽乌江（项羽本纪）；荆轲易水、高渐离击筑、专诸刺王僚（刺客列传）；冯唐易老（冯唐列传）；李广难封（李将军列传）；李斯黄犬（李斯列传）；伯夷叔齐采薇（伯夷列传）；徐福蓬莱（秦始皇本纪）。
- **《晋书》**：阮籍穷途哭（阮籍传）、绿珠坠楼（石崇传）、谢安东山（谢安传）—— 检索到《晋书》相应列传页面。

## 不确定 / 需留意之处（不藏）

1. **湘妃竹 出处卷次**。传世有两系：一系作《博物志》（识典古籍与搜韵转引《艺文类聚》均见「博物志云：舜南巡狩不返」），一系作《述异记》（「舜南巡，葬于苍梧之野，尧二女娥皇女英泪下沾竹，文悉为之斑」）。本库取 **《博物志·卷八》**；卷次靠《艺文类聚》转引与识典古籍卷八全文页互证，**未见该卷正文逐字比对**，如日后能核原本建议复核。
2. **张骞乘槎 的人名归属**。《博物志·卷十》原文只说「近世有人居海渚者」，与张骞挂钩是《荆楚岁时记》一系的后起附会（《重編國語辭典》「乘槎」条已说明此点）。故 source 仍作《博物志·卷十》，而在 gist 中明写「后人附会为张骞」。
3. **邹衍六月飞霜**。source 作 **《论衡·感虚》**（王充记「传书言：邹衍无罪，见拘于燕，当夏五月，仰天而叹，天为陨霜」）。另有一种说法把此事系于《淮南子》，然今本《淮南子》无此文，属佚文／转述，故未取。用例「张说《狱箴》『匹夫结愤，六月飞霜』」有百科专题页支撑，**未逐字核《张燕公集》原文**。
4. **蓝田玉烟**。此条严格说不是「事典」而是**诗学语典**：source 作司空图《与极浦书》引戴叔伦语（已核《司空表圣文集》有此篇），而用例举李商隐〈锦瑟〉「蓝田日暖玉生烟」。二者时序倒置（语典的记录晚于用例），若嫌不合体例可删此条（删后仍有 63 条，达标）。
5. **崔护人面桃花 / 刘禹锡玄都观**。source 作孟棨《本事诗》，分篇作「情感」「事感」。孟棨《本事诗》确分情感、事感、高逸、怨愤、征异、征咎、嘲戏七类，《重編國語辭典》等亦引《本事诗》为出处，但**具体条目归哪一类未逐条核对原书**。
6. **李龟年 / 公孙大娘 / 苏小小 / 木兰**。前两条的「出处」即杜甫本人诗篇（诗序记录本事），严格说属「诗中所咏之人」而非更早的典故来源；已如实标注 source 为杜诗篇名（含〈序〉）。苏小小的 source《玉台新咏·钱塘苏小歌》、木兰的 source《乐府诗集·横吹曲辞·木兰诗》为依据通说，**未逐字核《玉台新咏》《乐府诗集》原书卷次**。
7. **所用检索工具的能力边界**。`web_search` 只返回标题与链接、不返回正文摘要，`ctext.org` 拒绝抓取，`cnkgraph.com` 要求登录，故多数条目的核证是「标题＋权威站点题名」级别的旁证；对篇名与用例做了**逐字实抓核对**的仅限上文第 1、2 节明确点出的若干条（精卫填海、华亭鹤唳、鲛人泣珠、张骞乘槎等）。
