```

```

## 第 2 题　体裁：定风波
场景：城里租房住，房东要涨租，深夜把书装箱，窗外是一排正在盖的楼，塔吊的红灯一闪一闪。

```

窗外塔灯明复灭，似咽，无言相对只凄凉。

```

## 第 3 题　体裁：五言律诗
场景：母亲把父亲生前用的一把旧剃须刀收在抽屉最里面，刀柄上还缠着一圈胶布。

```
胶缠刀柄密，铁映指痕新。

```
